# Projects

This repository contains separate Node.js projects under `projects/`.

## Cable Finder

Telecom service availability app where a customer enters an address and sees all matching internet services.

```bash
cd projects/cable-finder
npm start
npm test
```

## Trading AI Agent

Paper-trading demo agent with market snapshot analysis, risk controls, and an in-memory paper broker.

```bash
cd projects/trading-ai-agent
npm start
npm test
```
