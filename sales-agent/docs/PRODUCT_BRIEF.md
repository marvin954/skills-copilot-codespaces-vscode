# Product Brief

## What this is

A **standalone SaaS** that runs an autonomous B2B sales pipeline:

**Generate leads → Contact → Qualify → Book appointments → Close deals**

## What this is NOT

- Real Estate Parcel Research Tool  
- Trading AI agent (repo root `src/`)  
- Any other project in this repository  

All code for this product lives under **`/sales-agent`**.

## Who it's for (operator)

Solo founder selling to SMBs:

- AI call centers & chatbots  
- Business / marketing automation  
- Web development services  
- Logistics & courier software  
- Local service businesses
